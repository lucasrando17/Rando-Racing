# Stable Manager — Fresh Restart

This is a completely rewritten Vite + React stable management app.

Important:
- There is no `Horse` icon import.
- There is no `<Horse />` component.
- Horse/stable sections use `BadgeCheck` from `lucide-react`.

## GitHub upload

Upload the CONTENTS of this folder to your new GitHub repository, not the folder itself.

The top level of the repo should show:

- `src`
- `public`
- `package.json`
- `vite.config.js`
- `index.html`
- `README.md`

## Vercel settings

Framework Preset: `Vite`  
Build Command: `npm run build`  
Output Directory: `dist`  
Install Command: `npm install`

## iPhone install

After deployment:
1. Open the Vercel URL in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
